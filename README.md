# G-Light-X11-Enviroment
Repository for the G-Light X11 Enviroment (GLXE), the LXQt X11 lightweight variant of Cluster-Wayland-Desktop-Enviroment (CWDE)

Note that GLXE is still in development and is still kind of unstable, If you want an controlled Altus experience, PLEASE use CWDE, since its more modern and stable KDE-based desktop.
